SavePoint

Seu backlog de jogos, finalmente organizado

Uma aplicação web para registrar o que você está jogando, acompanhar conquistas, guardar o histórico das suas runs de roguelike e anotar builds complexas — sem depender de planilha, bloco de notas ou grupo de WhatsApp.

O que dá para fazer

Backlog visual

Cadastre jogos com status, nota pessoal e categorias próprias. Busque e filtre sem recarregar a página.

Progresso de conquistas

Registre troféus obtidos e totais; a barra de progresso mostra a porcentagem de conclusão de cada jogo.

Histórico de runs

Anote cada tentativa com duração, resultado e causa da morte — e veja sua evolução ao longo do tempo.

Anotações de build

Guarde equipamento e distribuição de habilidades para não perder o raciocínio entre sessões longas de RPG.

Painel de estatísticas

Jogos zerados, tempo acumulado, nota média e runs registradas, calculados no servidor.

Exportação offline

Baixe seu backlog como um único arquivo HTML pesquisável, que funciona sem servidor e sem internet.

Principais telas

Backlog

Grade de jogos com busca, filtros, progresso de conquistas e ações de edição, run e exclusão.

Runs

Histórico filtrável por jogo e resultado, com criação, edição e exclusão das tentativas.

Builds

Anotações de equipamento e habilidades por jogo, também com criação, edição e exclusão.

Dashboard

Resumo de jogos zerados, horas acumuladas, nota média e total de runs registradas.

Screenshots reais podem ser adicionados em docs/assets/ antes da publicação final.

Como foi construído

Backend

  • Python + Flask com application factory e blueprints
  • Jinja2 para renderização das páginas
  • Camada de serviço com as regras de negócio isoladas
  • SQLAlchemy — consultas parametrizadas, sem SQL na mão

Frontend

  • HTML semântico e CSS Grid, sem framework de UI
  • JavaScript vanilla com fetch() assíncrono
  • Responsivo: sidebar no desktop, navegação inferior no celular
  • Acessibilidade com base semântica e checklist de auditoria em docs/ACESSIBILIDADE.md

Dados e infraestrutura

  • PostgreSQL (ou SQLite, sem nenhum setup)
  • Docker Compose para subir tudo com um comando
  • pytest — 56 testes de regra de negócio e de API
  • Sessão + hash de senha e proteção CSRF

Como executar

Sem nenhuma configuração: o projeto usa SQLite por padrão.

git clone <URL_DO_REPOSITORIO>
cd savepoint
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python database/seed.py
python run.py

Acesse http://localhost:5000 e entre com demo / SavePoint123. Para usar PostgreSQL, rode docker compose up -d db e aponte DATABASE_URL no .env.
